# Tài liệu dự án

Thư mục này là nguồn thông tin chuẩn cho thiết kế và phát triển `task-management-api`.

## Nội dung

- `product-spec.md`: mục tiêu, phạm vi và yêu cầu kỹ thuật.
- `architecture.md`: nguyên tắc kiến trúc và ranh giới hệ thống.
- `business.flow`: sơ đồ luồng nghiệp vụ bằng Mermaid.

## Quy trình Spec-Driven Development

1. Cập nhật yêu cầu trong `product-spec.md`.
2. Cập nhật luồng nghiệp vụ và kiến trúc liên quan.
3. Xác định tiêu chí chấp nhận có thể kiểm thử.
4. Triển khai đúng phạm vi đã mô tả.
5. Chạy kiểm thử và cập nhật tài liệu nếu hành vi thay đổi.

Không xem giả định hoặc mục `TBD` là yêu cầu đã được phê duyệt.
